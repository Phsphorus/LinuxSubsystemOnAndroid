## 2026-09-06 — portability and controlled-fallback foundation

- Hardened HALAgent authentication state before compatibility work. Secret creation uses an exclusive `0600` file creation path; startup corrects unsafe inherited secret state by rotating it, and the root-owned parent/secret directories are constrained to `0711` and `0700`. Existing pre-fix phone logs and bytecode caches were preserved under phone-side `tmp/backups`, then a fresh invalid/valid authentication test confirmed that no active log contained the secret or a raw pre-auth request.
- Added durable, generic backend rejection policy. `lsectl reject|disable <backend-id> [reason]`, `accept|enable <backend-id>`, and `rejections` operate on stable backend IDs for every module. A rejected candidate keeps its truthful probe state and reports `REJECTED BY USER`; lower accepted candidates are selected normally.
- Added detected architecture capability reporting for Android ABI, kernel, Termux userspace, Linux rootfs, and registered prebuilt artifacts. The canonical N6000 H.264 asset is explicitly checked as an arm64/rootfs-arm64 artifact and yields `UNSUPPORTED` rather than globally failing startup if incompatible.
- Added the real Storage Tier-Z `storage.termux-shared` backend. It binds normal Termux shared storage only when a higher accepted storage backend is unavailable or administratively rejected; no placeholder Z tier was added for modules without a practical baseline.
- Exercised forced fallback on the N6000: rejecting Tier-A Android shared Storage selected/reran Tier Z, survived a controlled RootStart restart, and returned to Tier A only after an explicit accept. The final override ledger is empty.
- Corrected the normal D-Bus lifecycle activation to use the registered `D-Bus` module identity. After a clean RootStart restart the generic system bus was selected/running and answered a Linux `dbus-send` request without manual activation.
- Revalidated generic N6000 regression paths after the changes: VirGL `glxgears` rendered 401 frames in five seconds; SensorBus/IIO reported two native plus twenty synthetic devices, accepted an event handshake, and delivered a 64-byte accelerometer stream sample with the test buffer state restored afterward.

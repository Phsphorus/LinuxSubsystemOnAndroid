# Runtime and generated artifacts

| Path or pattern | Classification | Owner / rule |
|---|---|---|
| `RootStart/Services/ModChroot/runtime/` | RUNTIME | logs, PID files, chroot switch/watch state, capability reports |
| `runtime/capability-framework/*.tsv` | RUNTIME | regenerated by framework refresh; do not package as source |
| `runtime/capability-framework/architecture.tsv` and `binaries.tsv` | RUNTIME | detected Android/kernel/Termux/rootfs architecture and registered prebuilt-artifact compatibility; regenerated on refresh |
| `RootStart/Services/ModChroot/state/backend-rejections.tsv` | RUNTIME CONFIGURATION | durable generic backend-rejection policy; directory is `0700` and ledger is `0600`; do not package a user's override |
| `/run/lsa-iio`, `/tmp/lsa-iio` | RUNTIME | IIO registry, sockets, logs, FUSE mount and process state |
| `/usr/local/lib/lsa/liblsa-iio-eventshim.so` | GENERATED | compiled per session from canonical `lsa_iio_eventshim.c` inside the Debian rootfs |
| `/usr/local/lib/lsa` | GENERATED deployment copy | supplied by the framework/module injector |
| `/usr/local/lib/halbridge` and `/usr/local/bin/HALAudio` | GENERATED deployment copy | supplied by `Modules/Audio/implementation/rootfs`; generic control client remains separately injected |
| managed blocks in `/etc/environment`, `/etc/asound.conf`, `/etc/resolv.conf` | GENERATED | LSA writes only its marked/owned portions |
| HALAgent audio/control and secret state | RUNTIME | deployment state and control data; never capture secrets in reports. The root-owned state parent is `0711`; the secret directory is `0700` and the secret itself is `0600`. |
| Capture provider camera frame cache and control state | RUNTIME | Termux-user provider data; never treat it as package source |
| `RootStart/Providers/Android/TermuxX11/run` and `logs` | RUNTIME | Root-provider PID, X11 launch record, and diagnostic log; never treat them as package source |
| `NonRootStart/Providers/Devices/Blackview/N6000/VideoEncode/state/run` | RUNTIME | Termux-UID N6000 video manager state, compiled GPU tap, source hash, and video-mode log |
| `/data/data/com.termux/files/home/.lsa-n6000-video-control.sock` | RUNTIME | Short, mode-0600 Termux-user control socket; it exists outside the provider path only to meet Android AF_UNIX pathname limits |
| `GPUBridge/run/.lsa-video` and `GPUBridge/run/mode` | RUNTIME | Device-provider video-mode endpoint and selected GPU mode; stopping VideoEncode restores generic mode and removes the video socket |
| `/usr/local/bin/lsa-h264-encode` and `/usr/local/lib/lsa/video/lsa_ahb_encode` | GENERATED deployment copy | Injected from the canonical VideoEncode module; the latter is a verified imported N6000 arm64 asset |
| `Workshop/` and archive snapshots | OBSOLETE evidence | not active runtime inputs |

Canonical source for this migration is `LSALIVE/source/`; package payloads are rebuilt from it. The live rootfs and runtime tree are not treated as authoritative source merely because they contain an injected copy.
